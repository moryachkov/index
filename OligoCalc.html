Лабораторный калькулятор
ОлигоРасчёт

Сколько аптамера нужно?

Введите молекулярную массу и условия ресуспендирования — калькулятор рассчитает количество вещества, массу сухого олигонуклеотида и ожидаемое поглощение при 260 нм (OE).

Исходные данные

Латинские A, C, G, T, U, I и N. Пробелы и переносы строк игнорируются. N — среднее по A/T/G/C; модифицированные основания не учитываются.

Расчёт OE при 260 нм

В режиме последовательности коэффициент будет рассчитан автоматически.
Для микропланшета/микрообъёма укажите эффективный путь, например 0,5 см.

Важно. OE (OD₂₆₀-единица) — количество вещества, соответствующее A₂₆₀ = 1 при пути 1 см и объёме 1 мл; количество OE для раствора: A₂₆₀ × объём(мл) / путь(см). Коэффициент экстинкции по последовательности рассчитывается по модели попарных коэффициентов; для неоднозначного основания N и модификаций оценка приблизительная. Для точного результата измерьте спектрофотометром. Табличные коэффициенты: СИНТОЛ.
Расчёт: C(мкМ) = C(мг/мл) × 10⁶ / MW(г/моль); C(нМ) = C(мкМ) × 1000; n(нмоль) = C(мкМ) × V(мкл) / 1000; m(мкг) = n(нмоль) × MW(кДа); для последовательности MW — сумма масс остатков минус 61,96 Да; ε для попарного метода — сумма табличных ε соседних динуклеотидов; для среднего метода — сумма ε оснований. A₂₆₀ = ε × C(моль/л) × путь(см); OE = A₂₆₀ × V(мл) / путь(см).
